## 3. 上下文管理协议（Context Window Protocol）

**目标：** 每次写作会话能在有限上下文内准确、连贯地写出3章。

### 3.1 每次会话的标准加载内容

```
必加载（固定，约36KB）：
  novel/bible.md         — 人物、道具、禁忌（16KB）
  novel/name_table.md    — 名称对照表（2KB）
  novel/continuity.md    — 当前连续性追踪（<3KB）

按需加载（当次批次，约5-8KB）：
  novel/outline.md       — 仅加载本批次相关章节段落
  novel/chapters/chXX.md — 上一批次最后2章（约20KB）

合计：~57KB，远低于上下文极限
```

### 3.2 continuity.md 格式（每批写完后更新）

```markdown
# 连续性追踪文档
## 当前写到：第X章·标题
## 时间线位置：2026年X月X日

## 角色当前状态
- 刘砺：[当前知道什么/正在做什么]
- 黄鹭：[当前知道什么/在哪里]
- 钱学渊：[当前承受的压力]
- 朱晓岚：[当前选择]
- 林恕：[是否已揭示温控记录]
- 张敏驰：[当前角色]

## 道具位置
- "Q"字笔：[在谁手里/在哪里]
- 便利贴：[在哪里]
- 第47页：[还是缺席的]
- "余音"邮箱：[是否已被刘砺发现]

## 未解决线索（读者已知但未解答）
1. 灰色夹克男人是谁
2. 尽调报告抄送列表里那个陌生邮箱
3. ...

## 已建立的细节（保持一致）
- 刘砺的摩斯电码敲桌习惯：三短一长，"V"
- 钱学渊特征：消毒水气味，语速慢半拍
- 澄域生物地址：西杉创意园B座7层
- 时间系统：刘砺入职于2024年4月（两年前）

## 本批次写作决策记录
- [记录任何偏离大纲的选择，及原因]
```

```

加载 novel/outline.md 中第X章到第Y章的部分，

本批次情感任务是：[一句话描述]。

写完每章后暂停，我确认后再写下一章。
```

## 4. 写作质量控制

### 4.1 每章完成后自检清单

```
□ 字数在2000-3000字之间
□ 名称对照表中所有替换名已使用（无真实公司名泄露）
□ 没有说破情感（只写行为，不写"他感到"）
□ 比喻不超过3个"像"字
□ 章节结尾没有点题
□ 有至少一个情感时刻（非情节推进性的）
□ 对话有停顿/未说完的句子
□ 所有道具出现位置与continuity.md一致
□ 时间线与整体时间线一致
```

### 4.2 合规自检清单

```
□ 无真实上市公司名称（爱尔、参天、泰格、信达等）
□ 无真实基金/VC名称（道彤/Dalton、未来资本等）
□ 无可追溯的真实临床数据（精确PK值等）
□ 无真实人名（监管官员、医生、投资人等）
□ 融资金额已做±偏移处理
□ 时间节点已做偏移处理
```
