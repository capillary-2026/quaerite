# Quaerite Corporate Deck

A self-contained, presenter-ready investor deck for Quaerite Biopharm Research,
anchored on **QBR202**, the **OcuHLE-X** durability platform, and **QBR207** option value.

## Open it

Open `Quaerite_Corporate_Deck.html` in any modern browser — no build step required.
Keep `qbr-logo.jpg` alongside it (the deck references it relatively).

## Navigate

| Action | Keys |
| --- | --- |
| Next / previous slide | `→` `←` · `Space` · `PageUp` / `PageDown` |
| First / last slide | `Home` / `End` |
| Overview grid (jump to any slide) | `O` |
| Fullscreen (presentation mode) | `F` |
| Close overview | `Esc` |

Touch swipe and on-screen prev/next controls are also supported, and you can deep-link
to a slide with a URL hash (e.g. `…Deck.html#9` opens slide 9). Use the browser's
**Print → Save as PDF** (landscape) to export a PDF — each slide becomes one page.
